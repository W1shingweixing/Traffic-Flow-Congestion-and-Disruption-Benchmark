# Local Causal Analysis

This folder contains the workflow for **local traffic causal analysis** around a selected traffic incident. The workflow first constructs a local benchmark case from the benchmark dataset, then analyzes traffic changes and causal relationships using **PCMCI** and **Granger Causality** method.

## Notebooks

### 1. `01_prepare_causal_analysis.ipynb` — Local Benchmark Construction

This notebook prepares a local benchmark case by:

1. Loading the raw benchmark datasets.
2. Performing data consistency checking.
3. Filtering eligible traffic incidents.
4. Selecting a representative incident.
5. Extracting the local road subgraph.
6. Extracting local traffic flow data.
7. Exporting the benchmark package to the `data/` folder.

### 2. `02_local_causal_analysis_pcmci.ipynb` — Local Causal Analysis (PCMCI)

Using the benchmark package generated by Notebook 1, this notebook:

1. Loads the selected incident and local benchmark data.
2. Characterizes traffic changes relative to a historical baseline.
3. Assesses PCMCI assumptions and practical data quality.
4. Infers historical lagged dependency relationships using **PCMCI**.
5. Evaluates parameter robustness through sensitivity analysis.
6. Assesses the spatial plausibility of stable relationships using the local road graph.
7. Produces a local causal benchmark report and exports the results.

### 3. `03_local_causal_analysis_pcmci_granger.ipynb` — Local Causal Analysis (PCMCI + Granger)

Using the benchmark package generated by Notebook 1, this notebook:

1. Loads the selected incident and local benchmark data.
2. Characterizes traffic changes relative to a historical baseline.
3. Infers historical lagged dependency relationships using **PCMCI**.
4. Assesses cross-method robustness using **Granger causality**.
5. Compares the inferred relationship rankings between PCMCI and Granger.
6. Produces a local causal benchmark report and exports the results.

## Data

The `data/` folder contains the benchmark package generated by Notebook 1.

| File | Description |
|------|-------------|
| `incidents_local.csv` | Selected incident information |
| `local_adjacency_binary.npy` | Binary adjacency matrix of the local road graph |
| `local_adjacency_weighted.npy` | Weighted adjacency matrix of the local road graph |
| `local_case_summary.csv` | Summary of the benchmark case |
| `local_graph_info.csv` | Mapping between station IDs and local graph indices |
| `raw_flow_local.csv` | Historical traffic flow data |
| `raw_flow_local.npy` | Historical traffic flow array |
| `sensor_meta_info_local.csv` | Metadata for the local traffic monitoring stations |

## Results

The `results/` folder contains outputs generated by Notebook 2, including:

- Figures (causal network visualizations)
- Maps (incident and station locations)
- Exported datasets

## Usage

Run the notebooks in the following order:

1. `01_prepare_causal_analysis.ipynb`
2. `02_local_causal_analysis_pcmci.ipynb`
3. `03_local_causal_analysis_pcmci_granger.ipynb`
