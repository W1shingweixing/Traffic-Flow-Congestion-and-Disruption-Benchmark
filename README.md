# Traffic Flow, Congestion, And Disruption Benchmark

This repository contains the materials, implementations, and documentation for the **Traffic Flow, Congestion, and Disruption Benchmark**.

The project is organized into the following branches:

- **`nswtraffic2025`** — Contains the NSW datasets used in this research, including traffic data, incident records, road information, weather data, and other related data sources.
- **`task1/2`** — Contains the implementation and documentation for:
  - **Task 1:** Traffic Forecasting
  - **Task 2:** Incident Classification
- **`task3/4`** — Contains the implementation and documentation for:
  - **Task 3:** Global Causal Analysis
  - **Task 4:** Local Causal Analysis

Please navigate to the relevant branch and refer to its **README.md** file for detailed information about the branch contents, methodology, implementation, instructions, and other relevant documentation.

Each branch provides specific information related to its respective dataset, tasks, and research components.
