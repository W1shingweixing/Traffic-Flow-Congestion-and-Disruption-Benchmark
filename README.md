# Causal Analysis

This repository contains the implementation and supporting files for **Task 3: Global Causal Analysis** and **Task 4: Local Causal Analysis**. It also includes the **Road Network Graph** used to create the adjacency matrix required for running the causal analysis tasks.

## Repository Structure

```text
.
├── Global Causal Analysis/
├── Local Causal Analysis/
├── Road network graph/
├── LICENSE
└── README.md
```

## Task 3: Global Causal Analysis

The `Global Causal Analysis` directory contains the code and related files required to perform **Task 3: Global Causal Analysis**.

This task focuses on analyzing causal relationships from a global perspective.

## Task 4: Local Causal Analysis

The `Local Causal Analysis` directory contains the code and related files required to perform **Task 4: Local Causal Analysis**.

This task focuses on analyzing causal relationships at the local level.

## Road Network Graph

The `Road network graph` directory contains the road network graph data used to create the **adjacency matrix** required for running the causal analysis tasks.

The adjacency matrix represents the connectivity between nodes in the road network and serves as an input for the analysis.

## Workflow

1. Prepare the road network graph.
2. Generate the adjacency matrix from the road network graph.
3. Configure the required input data and file paths.
4. Run **Task 3: Global Causal Analysis** using the files in the `Global Causal Analysis` directory.
5. Run **Task 4: Local Causal Analysis** using the files in the `Local Causal Analysis` directory.

## Requirements

Before running the tasks, make sure that:

- The required datasets are available.
- The road network graph is prepared correctly.
- The adjacency matrix has been generated.
- All required dependencies are installed.
- The input and output paths are configured correctly.
