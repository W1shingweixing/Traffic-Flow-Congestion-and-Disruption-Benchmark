# Global Causal Analysis

This folder contains the workflow for **global traffic causal analysis** across all 67 NSW benchmark stations. The workflow first constructs a system-level variable matrix from the benchmark dataset, then learns causal structure using **Lasso regression**, following the TraffiDent framework (Section 4.4).

## Notebooks

### 1. `03_prepare_global_causal.ipynb` — Global Benchmark Construction

This notebook prepares the global variable matrix by:

1. Loading the raw benchmark datasets.
2. Standardising station IDs and timestamps.
3. Checking station consistency across datasets.
4. Inspecting flow data quality per station.
5. Aggregating hourly flow data to daily station-level samples.
6. Counting daily incident occurrences per hazard type per station.
7. Merging flow, incident, and centrality variables into a single matrix.
8. Selecting final variables following TraffiDent Table 7.
9. Exporting the benchmark package to the `data_global_causal/` folder.

### 2. `04_global_causal_analysis.ipynb` — Global Causal Analysis

Using the benchmark package generated by Notebook 1, this notebook:

1. Loads the global variable matrix and variable names.
2. Validates the matrix (checks for missing values and constant columns).
3. Standardises all variables to zero mean and unit variance.
4. Defines DAG structural constraints following TraffiDent Section 4.4.
5. Fits Lasso regression to learn the causal weight matrix **W**.
6. Extracts and ranks significant causal edges.
7. Produces a causal graph visualisation and weight heatmap.
8. Exports results to the `results/` folder.

## Variables

Variables are grouped into three categories following TraffiDent Table 7:

| Category | Variables | Description |
|----------|-----------|-------------|
| **Meta-features** | is_weekend, precipitation_daily, degree_cent, between_cent, close_cent | Environmental and structural factors — cannot be caused by other variables |
| **Incident variables** | crash, breakdown, hazard, scheduled_roadwork, *(other types)* | Daily count of each hazard type near each station |
| **Traffic statistics** | mean_flow_hourly, is_major_incident, impact_hours | Traffic system outcomes — cannot cause other variables |

## DAG Constraints

Two structural constraints from TraffiDent Section 4.4 are enforced:

1. **No edges pointing toward meta-feature variables** — meta-features describe the environment and road structure, they cannot be caused by traffic flow or incidents.
2. **Traffic statistics cannot direct edges toward other variables** — traffic statistics represent outcomes of the system, not causes.

## Algorithm

**Lasso regression** (L1-regularised linear regression) is used as a practical alternative to TraffiDent's MM-DAG algorithm. MM-DAG is not publicly available. For each target variable, we regress it on all eligible predictor variables. The L1 penalty automatically shrinks unimportant coefficients to zero, keeping only variables with genuine predictive power. A non-zero coefficient from variable A to variable B is interpreted as a causal link.

| Aspect | TraffiDent (MM-DAG) | This work (Lasso) |
|--------|--------------------|--------------------|
| Algorithm | MM-DAG (score-based, multi-modal) | Lasso regression (L1 regularisation) |
| Data types | Scalar + functional time-series | Scalar (daily aggregates) |
| Stations | 16,972 sensors, 4 districts | 67 NSW stations |
| Time span | 3 years (2022–2024) | 1 year (2025) |
| Variable categories | 3 (meta, incident, traffic) | 3 (same structure) |
| DAG constraints | Same 2 constraints | Same 2 constraints |
